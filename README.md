## Work Session Summary

Every work session starts with the studio source of truth, not scattered memory.

The basic workflow is:

1. Open `STUDIO_DASHBOARD.md`.
2. Confirm the active app and milestone.
3. Review `DECISIONS.md` and `APP_REGISTRY.md`.
4. Pick one small, revenue-relevant task.
5. Turn that task into a Codex-ready ticket.
6. Let Codex implement only that scoped ticket.
7. Review, validate, test, commit, and push.
8. Update the studio docs before ending the session.

The session is not complete until this repo accurately describes the current state of the work.

**TinySheets Worksheet Generator**

TinySheets helps K-2 teachers, tutors, and homeschool parents generate clean one-page math and vocabulary worksheets in under 60 seconds.

## Current MVP Goal

The first TinySheets MVP only needs to prove this:
