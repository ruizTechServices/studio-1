# RuizTech Studio

RuizTech Studio is the source-of-truth workspace for planning, building, reviewing, and launching RuizTechServices software products.

This repository is not a random notes folder.

It is the operating system for creating focused, sellable, maintainable apps without losing context between work sessions.

## Current Studio Focus

The current primary product is:

---
Below is the current project description(This can be changed as needed):

---

**TinySheets Worksheet Generator**

TinySheets helps K-2 teachers, tutors, and homeschool parents generate clean one-page math and vocabulary worksheets in under 60 seconds.

## Current MVP Goal

The first TinySheets MVP only needs to prove this:

A logged-in user can generate a simple K-2 worksheet, preview it, save it, and export it as a PDF.

Anything beyond that is deferred until the core workflow works.
